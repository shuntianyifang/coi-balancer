① 数据与场景

输入、输出是单次数量；duration 是模拟秒，统一换算为 /60。power 是满载净耗电 MW（发电为负）。工人按配置建筑数量计算；维护是运行量加权估算，实际配置请参考整数建筑数。每条配方独占建筑，暂不支持同机多配方排程。

数据格式说明

min / max 是等效满载建筑运行量；令两者相等可固定满载。cost 是优化权重。source、status、version 保存数据证据。农业应将完整轮作折算为一个配方；不自动推断肥力公式。修改 JSON 后点击“应用数据”。
